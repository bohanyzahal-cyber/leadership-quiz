## שני הסיכומים — ומה זה אומר על ההיקף

המאגר נבנה בתחילה מסיכום קורס מלא. לאחר מכן התקבל **סיכום מקוצר למבחן**, שהוא צר יותר: נשמטו ממנו נושאים שלמים, ונוספו נושאים שלא היו בקודם.

**נוסף בסיכום המקוצר** (ונכתבו עליו שאלות חדשות): מודל **טאקמן** לשלבי התפתחות צוות · ההבחנה בין **קבוצה לצוות** · **מודל חמשת הגורמים (Big Five)** ודגשי המרצה עליו · 14 עקרונות **פיול** · נוסחת **MPS** · מודל **SWOT** · **מנהיגות עסקתית** כשם נרדף למתגמלת · **טפלון** · המסגרת **מוטיבציה 1.0/2.0/3.0** · ניסויי **הארלו** על קופי רזוס.

**נשמט מהסיכום המקוצר:** רדין · וורום-ייטון · תיאוריית המשאבים הקוגניטיביים · נתיב-מטרה (האוס) · צדק ארגוני וארבעת סוגיו · שלוש צורות ההוגנות · פרידמן · אפקט סוייר · ניסויי דיסי.

### מה נעשה עם 51 השאלות שנשמטו

הן **לא נמחקו** — הן נכונות עובדתית — אלא סומנו במקור **`מעבר לסיכום`**, וההפרדה מהן מוחלטת:

- **מחוץ להיקף ברירת המחדל.** ברירת המחדל היא **היקף המבחן** — 441 שאלות.
- **תווית אדומה** ⚠ מחוץ להיקף המבחן ליד כל שאלה כזו, גם בתרגול וגם בהדפסה.
- **אזהרה במסך ההגדרות** ברגע שהבחירה כוללת אותן.
- **אינן בחוברת החומר הפתוח.** החוברת נבנתה מהסיכום המקוצר בלבד.

### תיקוני עובדה שהסיכום החדש חשף

- **חוללות עצמית ≠ אפקט פיגמליון.** הסיכום הישן איחד ביניהם. החדש מפריד: חוללות עצמית (Self-Efficacy, **בנדורה**) היא אמונת האדם ביכולתו; פיגמליון הוא השפעת ציפיות של **אחרים**.
- **קיומיים / קשר / צמיחה הם של אלדרפר (ERG)** — שלוש רמות המקבצות את חמש הרמות של מסלאו, ולא שמות של קומות בפירמידה של מסלאו עצמו.
- **תיאוריות התהליך הן שלוש** (לוק, אדמס, ורום). פורטר-ולולר אינו נכלל.
- **ניסויי הארלו** בסיכום החדש הם ניסויי ההיקשרות בקופי רזוס («אם המגבת ואם התיל»), ולא ניסוי המנגנון המכני.

> נקודה אחת נותרה סותרת בתוך הסיכום עצמו: גוף הסיכום אומר שממדי אוהיו **אינם תלויים** זה בזה, ואילו מפתח התשובות שבסופו מנוסח «תלויים זה בזה». נכתב לפי גוף הסיכום, וההסתייגות מופיעה בחוברת.

## תכונות

- **מצב תרגול** — משוב והסבר אחרי כל שאלה, ותרגול חוזר של השגויות. אורך סבב נבחר (20 / 40 / הכל).
- **סימולציית מבחן** — 25 / 40 / הכל, שעון אופציונלי, מפת שאלות, ציון וסקירה מלאה של כל שגיאה.
- **הדפסת שאלות** — עם תשובות והסברים, או השאלות בלבד (שתי עמודות, צפוף).
- **פריסה מאוזנת בין נושאים** (ברירת מחדל) — 21 הנושאים אינם שווים בגודלם, ודגימה אקראית הייתה מרכזת סבב קצר בשניים-שלושה נושאים.
- **ערבוב תשובות בכל סבב** · סינון לפי נושא ולפי מקור · מצב כהה/בהיר · מותאם למובייל.

## בנייה מחדש

```bash
cd src && python build.py
```

```bash
cd exam && python build.py
```

`src/build.py` משבץ את `bank*.js` בתוך `src/template.html` וכותב את `index.html` ואת העותק בתיקיית הקורס. `exam/build.py` עושה את אותו הדבר לחוברת, מ-`exam/content.js`. סכמת שאלה:

```js
{t:"נושא", s:"מקור", q:"השאלה", o:["א","ב","ג","ד"], c:1, e:"הסבר"}
```

`c` הוא אינדקס התשובה הנכונה **לפני** הערבוב. מכיוון שהאפליקציה מערבבת את סדר האפשרויות בכל הרצה, **אין לכתוב מסיחים תלויי-מיקום** ("כל התשובות נכונות") — הבנייה נכשלת עליהם.

### הבדיקות שרצות בכל בנייה

- **מבנה** — 4 אפשרויות שונות, שדות מלאים, אין כפילויות, אין מסיחים תלויי-מיקום, אין ביטויים חוזרים, הסבר באורך סביר.
- **התאמת מפתח** — התראה כשההסבר מתאר אפשרות אחרת מזו שסומנה כנכונה.
- **תל האורך** — הבדיקה החשובה. כשכותבים שאלות בכמות, התשובה הנכונה יוצאת כמעט תמיד הארוכה ביותר, ואז אפשר לענות נכון בלי לקרוא. מקרי ≈ 25%; חריגה מעל 45% נכשלת.

  נכון לעכשיו: **ארוכה 26% · קצרה 9% · "החורגת ביותר" 18%** — אף אסטרטגיה עיוורת אינה עדיפה על ניחוש.
- **בחוברת** — בקרת גלישה: עמוד שתוכנו חורג מגבולות A4 מסומן באדום בדפדפן, והסטטוס בראש העמוד מדווח «תקין».
