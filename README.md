# בוחן תרגול — מנהיגות בניהול

אפליקציית תרגול למבחן בקורס **מנהיגות בניהול** (בר-אילן), שנבנתה מסיכום הקורס.

**▶ פתחו את `index.html`** בכל דפדפן — קובץ יחיד, ללא התקנה וללא תלויות חיצוניות. עותק זהה יושב בתיקיית הקורס בשם `בוחן תרגול - מנהיגות בניהול.html`.

**מאיפה להתחיל:** בחרו באתר את ההיקף **שאלות מבחן** (77 שאלות). אלו נוסחו מרשימת השאלות שבסוף סיכום הקורס — כלומר מהחומר הקרוב ביותר לנוסח האמיתי של המבחן. משם המשיכו ל**הכל**.

## תכונות

- **מצב תרגול** — משוב מיידי והסבר מנומק אחרי כל שאלה, ותרגול חוזר של השגויות בלבד. אורך הסבב נבחר (20 / 40 / הכל, ברירת המחדל 20) — הכפתור לתרגול השגויות מופיע רק במסך שבסוף הסבב, ולכן סבב קצר הופך אותו לשמיש.
- **סימולציית מבחן** — 25 / 40 / כל השאלות, שעון אופציונלי (30/45/60 דק'), מפת שאלות למעבר מהיר, הגשה וציון, וסקירה מלאה של כל שגיאה עם התשובה הנכונה וההסבר.
- **פריסה מאוזנת בין נושאים** (פעילה כברירת מחדל) — 18 הנושאים אינם שווים בגודלם, ולכן דגימה אקראית פשוטה מרכזת סבב קצר בשניים-שלושה נושאים ומחמיצה אחרים. הפריסה המאוזנת לוקחת לסירוגין מכל נושא. ניתן לכבות.
- **ערבוב תשובות בכל סבב** — סדר האפשרויות מתערבב מחדש בכל הרצה, כך שאי אפשר לזכור מיקומים.
- סינון לפי נושא ולפי מקור · מונה נכונות/שגויות ואחוז הצלחה · מצב כהה/בהיר · מותאם למובייל.

## בנייה מחדש

השאלות אינן נערכות ישירות ב-`index.html` אלא במקורות:

```bash
cd src && python build.py
```

`build.py` משבץ את `bank*.js` לתוך `template.html` וכותב את `index.html` וגם את העותק בתיקיית הקורס. הסכמה של כל שאלה:

```js
{t:"נושא", s:"מקור", q:"השאלה", o:["א","ב","ג","ד"], c:1, e:"הסבר"}
```

`c` הוא אינדקס התשובה הנכונה **לפני** הערבוב. מכיוון שהאפליקציה מערבבת את סדר האפשרויות בכל הרצה, **אין לכתוב מסיחים תלויי-מיקום** ("כל התשובות נכונות", "תשובות א'+ב'") — הבנייה נכשלת עליהם.

### הבדיקות שרצות בכל בנייה

- **מבנה** — 4 אפשרויות שונות לכל שאלה, שדות מלאים, אין שאלות כפולות, אין מסיחים תלויי-מיקום, אין ביטויים חוזרים בתוך אפשרות, והסבר באורך סביר.
- **התאמת מפתח** — התראה כשההסבר מתאר אפשרות אחרת מזו שסומנה כנכונה.
- **תל האורך** — הבדיקה החשובה. כשכותבים שאלות בכמות, התשובה הנכונה יוצאת כמעט תמיד הארוכה ביותר, ואז אפשר לענות נכון בלי לקרוא. הבדיקה מדווחת כמה אחוזים מהתשובות הנכונות הן הארוכה או הקצרה ביותר, וכמה שווה האסטרטגיה "בחר את החורגת ביותר באורכה". מקרי ≈ 25%; חריגה מעל 45% נכשלת.

  נכון לעכשיו: **ארוכה 26% · קצרה 8% · "החורגת ביותר" 17%** — כלומר אף אסטרטגיה עיוורת אינה עדיפה על ניחוש. אימות עצמאי: מענה על סימולציית מבחן לפי מיקום קבוע נתן 20%.
